# Right Panel

**A liquid side panel that lives on the edge of your screen.**<br>
Move your mouse to the right edge and it pours out: emoji, clipboard history, colors, notes, your apps and two dozen handy tools.

## Features

| | |
|---|---|
| 😊 **Emoji picker** | Search in English or Persian, categories, recents, and **259 country flags**. Click to type it straight into the app you were using |
| 📋 **Clipboard history** | Text *and images*, search, ☆ pin favourites that survive restarts |
| 🎨 **Color** | Eyedropper (pick any pixel on screen), HEX / RGB / HSL, palette, recent colors |
| 📸 **Screenshot** | Opens the system snipping tool |
| 📝 **Notes** | As many notes as you like, in tabs, saved as you type — double-click a tab to name it |
| 🧩 **Your apps** | Pin apps or shortcuts — add them in Settings or just **drag them onto the panel** |
| 📁 **Folders** | Drop a folder and it lands in the Folders tool, not the dock. Add, remove and drag to reorder, then click to open |
| 🔎 **Search** | A dozen engines in categories — Google, Bing, DuckDuckGo, Brave, Reddit, Stack Overflow, YouTube, Images, Wikipedia, Translate, News, Maps, GitHub — each with its own logo, or just type a URL. The box detects Persian/Arabic and puts a direction button on the matching side |
| ✂️ **Snippets** | Save text you type often and paste it with one click. `{{date}}`, `{{time}}` and friends drop in **where your caret is**, spaced so the text around them stays tidy |
| 🔢 **Num Convert** | Type once, get it in English, Persian and Arabic digits — click any output to copy it |
| 🌐 **Network** | Your public address and where it says it is, with the country's flag. Ask once, then *Refresh* when you want a new reading |
| 🖥️ **System info** | OS, system type, processor, graphics, memory and uptime, read fresh each time you open it |
| 📅 **Calendar** | One grid in **Gregorian or Jalali**, drawn right to left for the Iranian week. Click a day and the date cards and boxes follow it; the heading shows the same date in the other calendar |
| 🔢 **QR code** | Type anything, copy the result as an image or as SVG |
| 🧮 **Calculator** | Full keyboard: digits, `+ - * / ( ) ^`, `Enter`, `Backspace`, `c`. Long numbers shrink to fit and keep their last digits |
| 🔐 **Password** | Strong passwords with a live strength meter |
| 🎲 **Generate** | UUIDs, dates, lorem ipsum and more |
| 📏 **Units** | Length, mass, volume, **data sizes** (byte → petabyte), speed, temperature, frequency — type `1.5gb` or `1,024 KB` |
| ⏱️ **Timer · Stopwatch · World clock** | With laps, presets and your favorite cities, in 24h or 12h |
| 🎵 **Media** | Play/pause, next, previous, volume |
| 🔤 **Text tools** | Type or paste text, then UPPER/lower/Title, trim, one line, slug, Base64, URL encode, word count |
| ☀️ **Keep awake · Screen off · Lock · Pin window on top · Task manager** | One-click system helpers |

**Also**
- **Persian & Arabic**: type in any search box or note and the caret flips to match — Persian and Arabic text throughout the panel is set in the [Arad](https://github.com/MDarvishi5124/Arad) typeface, with Latin left to your system font
- **Emoji search works in Persian too** — keywords come from [CLDR](https://cldr.unicode.org/), so `خنده` finds 😂, `آتش` finds 🔥 and `ایران` finds 🇮🇷
- **Emoji stay put while you paste** — click as many as you like; the picker only closes once your mouse leaves it
- **Drag a file onto the panel** to pin it, or right-click it → *Add to Right Panel* (Windows; on Windows 11 under *Show more options*). Folders go to the **Folders** tool instead
- **Left or right edge**, and pick which monitor it lives on (*Settings → General*)
- **Open on a key of your choosing** — the panel appears when you reach the screen edge, or only while you hold a combination you set, such as `Ctrl + Shift + Space` (*Settings → Keybinds*)
- **Bind a key to any tool** — including the eyedropper (*Settings → Keybinds*)
- **Built-in updater**: Right Panel checks GitHub once a day and can download and run the new installer for you (*Settings → General*)
- Only one copy runs at a time

**Make it yours**
- Drag any tool **between the dock and the More grid**, reorder, hide or show it (also in *Settings → Widgets*)
- Hover an app in the dock for its name — a proper tooltip, not the browser's default
- **15 themes** (Midnight, Graphite, Ocean, Grape, Forest, Wine, Espresso, Neon, Sunset, Snow, Sand, Sky, Rose, Mint, Lilac) + custom color. Scrollbars follow the theme
- Build your own theme from two colours you pick, and every other colour is derived from them
- Liquid spring animations, magnify-on-hover, sliding active pill
- Tray icon, start with Windows / at login
- The panel only takes clicks where it can actually be clicked — the rest of the strip lets them through to whatever is behind

## Install

| Platform | File | Notes |
|---|---|---|
| **Windows 10/11** | `RightPanel-Setup.exe` | Recommended. Per-user install, no admin needed |
| | `RightPanel-portable.exe` / `.zip` | No install, just run it |
| **macOS 11+** *(beta)* | `RightPanel-macos-arm64.dmg` / `-x64.dmg` | Not notarized: right-click the app → **Open** the first time |
| **Linux** *(beta)* | `.deb` or `.tar.gz` | Needs WebKitGTK 4.1. Works on X11 and Wayland (runs through XWayland; `RIGHT_PANEL_BACKEND=wayland` opts out) |

Windows uses the built-in WebView2 runtime (already on Windows 10/11), which is why the app stays small — the extra weight is the two bundled fonts (Twemoji and Arad).

### Beta notes for macOS and Linux
Core features work everywhere. A few are Windows-only for now and are hidden on other systems: *auto-paste into the previous app* (items are copied instead), *screen eyedropper*, *Pin window*, *Show desktop* and app icons. On Wayland (GNOME, KDE…) the app runs through XWayland so it can sit on the screen edge; the tray icon needs `libayatana-appindicator3-1`. Media keys on Linux use `playerctl` / `pactl`.

## Build from source

```bash
git clone https://github.com/WhoisNeon/right-panel
cd right-panel
cargo build --release
```

Linux needs `libwebkit2gtk-4.1-dev libgtk-3-dev libx11-dev`. The Windows installer is built with [Inno Setup](https://jrsoftware.org/isinfo.php): `iscc installer/right-panel.iss`.

Built with Rust, [tao](https://github.com/tauri-apps/tao) + [wry](https://github.com/tauri-apps/wry). The whole UI is one HTML file: [`src/ui.html`](src/ui.html).

Settings live in `%APPDATA%\RightPanel` (Windows), `~/Library/Application Support/RightPanel` (macOS) or `~/.config/right-panel` (Linux).
